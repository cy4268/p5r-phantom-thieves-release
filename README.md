# 心之怪盗团

《女神异闻录5 皇家版》同人角色卡（SillyTavern）的发布仓库。这里只放构建好的游戏程序、图片和角色卡文件，卡里的入口脚本会通过 jsDelivr 按版本号从这里加载。

## 下载与使用

1. 下载 [`cards/心之怪盗团-0.3.0.card.json`](cards/心之怪盗团-0.3.0.card.json)，在 SillyTavern 里导入。
2. 导入时选择导入内嵌世界书，并启用卡内脚本（需要酒馆助手扩展）。
3. 点击输入框上方的「进入怪盗团」开始游戏。

预设兼容、游玩方式等说明，见角色卡的"创作者备注"。

## 升级与音乐

从公开版0.2.2或更早版本升级到0.3.0，请导入新卡和内嵌世界书后新建聊天。旧聊天继续使用[0.2.2角色卡](https://github.com/cy4268/p5r-phantom-thieves-release/blob/0.2.2/cards/心之怪盗团-0.2.2.card.json)及原版本程序，不要直接覆盖旧聊天进度。

手机内保留聊天／音乐页面和按场景选曲功能。本次公开包不附本机游戏提取的音源，曲目会提示音源待补齐；不影响剧情与战斗。
